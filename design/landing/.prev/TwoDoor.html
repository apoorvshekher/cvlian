Resume / Editor

A résumé editor that compiles real LaTeX in your browser.

No server sees your résumé, because there is no server. Choose where you want it kept — you can change your mind later without losing anything.

Option one
Keep it on this machine

Nothing leaves the browser. Start typing in about two seconds, with no sign-in of any kind.

  • ✓No account, no email address, no consent screen
  • ✓Works offline once the page has loaded
  • —Stays in this one browser on this one machine
  • —Clearing site data erases it — export a backup
Start without an account

Your workspace lives in this browser's storage. Export writes a single JSON file you can re-import anywhere.

Option two
Sync it to your own Drive

One file in your Google Drive, written straight from this page. Your résumé follows you between machines.

  • ✓Same résumé on your laptop, desktop and any browser
  • ✓We can only see the one file we create, never the rest of your Drive
  • ✓We never learn your name or email — we don't ask for them
  • —Needs a Google account and a one-time consent screen
Continue with Google

Uses the drive.file scope: per-file access, granted by Google, limited to files this app created.

Either way, the editor is identical. Start locally and connect Drive later, or disconnect and keep working — your branches and saved versions come with you.
