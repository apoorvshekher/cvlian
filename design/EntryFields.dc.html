Anything that doesn't fit a type keeps the old free-form shape under Custom — a left column, a right column and bullets. Existing resumes import into Custom untouched, then upgrade to a type whenever you want. Because dates are now real fields, a theme can right-align them, stack them, or drop them into a sidebar without you re-typing anything.
